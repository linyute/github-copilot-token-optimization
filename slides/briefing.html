本內容為社群指引，並非 GitHub 或 Microsoft 的官方政策。

了解你在為什麼付費

輸入

系統提示詞、指示、檔案、歷程記錄、工具結構描述，以及你的提示詞。

輸出

回應、推理與工具呼叫。通常是成本最高的 token 類型。

快取輸入

穩定的請求前綴可以以較低的有效成本重複使用。

代理程式迴圈

每一次讀取、命令、重試與重工步驟，都會讓成本不斷累積。

從哪裡開始

  1. 限制輸出。不再為不需要的文字付費。
  2. 縮小內容脈絡。讓常駐的指示與檔案保持聚焦。
  3. 減少工具額外負擔。只載入所需的 MCP 工具，並壓縮命令輸出。
  4. 避免重工。選擇模式與模型，就計畫達成共識，然後驗證。

1. 從簡潔的輸出開始

簡潔回答。保留採取行動所需的證據。

依任務選擇格式。Caveman 是選用的，並不保證能降低成本。

請就總成本與正確性，比較預設、簡潔與 Caveman。證據與通訊協定。

2. 壓縮常駐指示

保留

專案陷阱、必要命令、命名、架構規則、輸出限制。

移除

樣板內容、程式碼中可見的事實、重複的規則、偶爾才用到的檢查清單。

.github/copilot-instructions.md 中的每個 token 都會被重複付費。請將少用的指引放在限定範圍或隨需載入的檔案中。

3. 刻意鎖定內容脈絡

  • 關閉不相關的編輯器索引標籤，避免附加範圍過廣的檔案。
  • 針對特定路徑的規則，使用 applyTo 指示檔案。
  • 在進行 AI 工作之前，先將富格式輸入轉換為 Markdown。
  • 傳送相關的計畫與檔案，而不是整個專案的歷程記錄。

4. 保護快取的前綴

在一項長時間的任務中，請保持下列項目穩定：

{ 模型、推理強度、已載入的技能、MCP/工具集、代理程式/設定檔 }

變更這些設定可能會失去快取節省的效益。需要變更時，請以簡短的交接開啟新的聊天。

5. 使用最小且足以勝任的模式

Ask

問題、說明、決策。不需要工具。

Edit

檔案與意圖都已知、範圍明確的變更。

Agent

需要探索、命令與驗證的多檔案工作。

Ask 模式就能回答的問題，不要使用 Agent 模式。

6. 依任務安排模型路由

  • 日常工作優先使用 Auto。
  • 查詢、語法與小型機械性編輯使用輕量模型。
  • 規劃、架構與困難的偵錯使用強推理模型。
  • 當計畫已涵蓋困難的決策後，使用較便宜的執行模型。

請在長時間工作之前選好推理強度。如果任務有所變化，請以簡潔的交接重新評估。

7. 先規劃，再以全新工作階段執行

記錄驗收條件、可能涉及的檔案、風險與驗證方式。只帶著該份交接開始執行。

8. 讓 MCP 基準線保持精簡

  • 已載入的工具定義會增加內容脈絡；主機可能會延後載入未使用的結構描述。
  • 停用此儲存庫或任務不需要的伺服器與擴充功能。
  • 對重複的工作流程，使用乾淨的設定檔或專注的代理程式。
  • 在 Copilot CLI 中執行 /context，查看載入了什麼。

9. 只壓縮一次 shell 輸出

RTK

針對常見開發人員命令輸出的編譯預設值。

snip

YAML 管線與本機節省追蹤。

每個命令路徑只選擇一個篩選層。預設情況下不要同時堆疊兩者。

10. 重複使用程式碼庫地圖

Graphify 只需對大型儲存庫建立一次地圖，之後代理程式便查詢結構，而不是反覆讀取範圍廣泛的檔案集。

graphify query "where is auth middleware?"
graphify path "Router" "Database"

最適合大型儲存庫與重複的代理程式工作階段。對於小型的一次性變更，請略過它。

11. 讓 token 用量可見

工作階段內

使用 /context 檢查 Copilot CLI 的內容脈絡壓力與已載入的工具。

跨工作階段

Tokentop 會顯示本機即時的 token、成本、燃燒速率與預算警示。

請用這些工具找出浪費；兩者都不會壓縮內容脈絡。

12. 設定穩定的工作階段執行框架

模型 + 推理強度 + 模式 + 代理程式 + 技能 + MCP 工具 + 輸出篩選器 + 儲存庫指示

請在長時間工作之前選好這些設定。如果需要變更，請帶著相關的內容脈絡開啟新的工作階段。

13. 完成前先驗證

  1. 指明驗收條件。
  2. 執行目標測試、建構或檢查。
  3. 回報證據，而不是籠統的「完成」。

請在審查發現遺漏的工作之前，先檢查結果。

14. 採用並持續落實

第 1 週

限制輸出。精簡儲存庫指示。

第 2 週

刻意安排 Ask、Edit 與 Agent 的使用。

第 3 週

稽核 MCP 工具與命令輸出。

第 4 週

先規劃的工作流程、快取穩定性與用量檢視。

每項任務：限制輸出、鎖定內容脈絡、選擇執行框架、規劃並驗證。
