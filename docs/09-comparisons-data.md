# 第 3 部分：比較與資料

[← 返回指南](index.md)

請依技術所改變的成本來比較。較短的回應、較小的輸入檔案、較少的代理程式步驟，以及較低的模型費率，是不同的成果。

## 依機制選擇

| 機制 | 可嘗試的做法 | 要衡量的項目 | 完整指引 |
|---|---|---|---|
| 輸出長度 | 簡潔的回應、適當時僅回應程式碼、明確的格式 | 輸出 token、完整性、計費的任務成本 | [輸出控制](05-output-control.md) |
| 提示詞清晰度 | 移除贅詞；說明需求與例外情況 | 提示詞 token、修正次數、任務成功率 | [提示詞壓縮](02-prompt-compression.md) |
| 載入的上下文 | 較小的常駐檔案、限定範圍的指示、相關檔案 | 實際載入的上下文與快取使用量 | [上下文管理](04-context-management.md) |
| 指示的相關性 | 移除可自行發現、過時與重複的指引 | 在相同存放庫任務上的正確性與成本 | [常駐上下文問題](07-agents-md-problem.md) |
| 工具額外負擔 | 限定 MCP 範圍；使用單一 shell 輸出篩選器；重複使用結構地圖 | 載入的結構描述、結果大小、遺漏的診斷細節 | [MCP 與工具成本](08-mcp-tool-costs.md) |
| 重工與代理程式步驟 | 適當的模式、清楚的計畫、有針對性的驗證 | 被接受的工作、重試次數、呼叫次數、總成本 | [工作流程最佳化](06-workflow-optimization.md)與[單位 Token 產出](13-outcome-per-token.md) |
| 計費費率 | 讓模型與投入程度符合任務 | 在可比較的任務品質下的計費成本 | [模型選擇與定價](11-models-and-pricing.md) |
| 支出限制 | 預算、群組、模型存取政策 | 相對於預算的支出；被阻擋的有用工作 | [企業治理](12-enterprise-governance.md) |

這是一份選擇指南，並非通用節省百分比的排名。

## 在原始範圍內解讀證據

| 證據類型 | 能確立的事項 | 無法確立的事項 |
|---|---|---|
| 手寫的前後對照 | 措辭可能如何改變 | 實際的模型輸出、品質或典型的節省幅度 |
| 離線 tokenizer 計數 | 該 tokenizer 下的文字長度 | 提供者計費的用量或金錢上的節省 |
| 受控的回應風格比較 | 其任務與對照條件下的輸出差異 | 整個工作階段的成本或其他模型的行為 |
| 重複並經驗證的代理程式任務 | 該測試框架下的任務成果與用量 | 對每個存放庫或工作流程的保證 |
| 工具廠商的基準測試 | 值得測試的候選方案 | 你的帳單確實降低的獨立證明 |

[Caveman 證據與三組協定](05-output-control.md#caveman-optional-output-style)區分了預設回覆、一般的簡潔，以及整體任務成本。[語言比較](03-language-comparison.md)包含各語言的表格；[基準測試討論](13-outcome-per-token.md#benchmarks-useful-not-decisive)則涵蓋測試框架與分數的限制。

## 不要把節省百分比相加

兩種技術可能移除相同的 token，它們的效果並不可相加。

舉例說明：如果輸出占帳單的 10%，將該輸出減少 10%，在不計指示額外負擔或行為改變的情況下，可節省帳單的 1%。這只是算術，並非衡量到的 Caveman 結果。

請分別衡量輸入、快取、輸出、（若有揭露的）推理，以及總計費成本。比較相同的任務與驗收檢查。關於計費單位，請參閱[模型選擇與定價](11-models-and-pricing.md)。

## 記錄足以重現主張的資訊

請註明來源、日期、模型、技能／工具版本、任務集、對照組、執行次數、tokenizer 或提供者用量，以及品質檢查。請標示廠商自行回報的結果與未經驗證的估計。

來自單一任務或單次執行的結果，可以提示一項值得進行的測試，但不應成為本指南中預設的節省範圍。
