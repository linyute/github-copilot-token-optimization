# 第 3 部分：比較與資料

[← 返回指南](index.md)

請依據各技巧所改變的成本來比較。較短的回應、較小的輸入檔案、較少的代理程式步驟，以及較低的模型費率，是不同的成果。

## 依機制選擇

| 機制 | 可嘗試的做法 | 應量測的項目 | 完整指引 |
|---|---|---|---|
| 輸出長度 | 簡潔的回應、適當時僅輸出程式碼、明確的格式 | 輸出 token、完整性、計費的任務成本 | [輸出控制](05-output-control.md) |
| 提示詞清晰度 | 移除贅詞；說明需求與例外情況 | 提示詞 token、修正次數、任務成功率 | [提示詞壓縮](02-prompt-compression.md) |
| 已載入的內容脈絡 | 較小的常駐檔案、限定範圍的指示、相關的檔案 | 實際載入的內容脈絡與快取使用情形 | [內容脈絡管理](04-context-management.md) |
| 指示的關聯性 | 移除可自行發現、過時與重複的指引 | 在相同儲存庫任務上的正確性與成本 | [常駐內容脈絡問題](07-agents-md-problem.md) |
| 工具的額外負擔 | 限定 MCP 的範圍；使用單一個 shell 輸出篩選器；重複使用結構性地圖 | 已載入的結構描述、結果大小、遺漏的診斷細節 | [MCP 與工具成本](08-mcp-tool-costs.md) |
| 重工與代理程式步驟 | 適當的模式、明確的計畫、針對性的驗證 | 已接受的工作、重試次數、呼叫次數、總成本 | [工作流程最佳化](06-workflow-optimization.md)與[每個 Token 的成果](13-outcome-per-token.md) |
| 計費費率 | 讓模型與推理強度符合任務 | 在可比較的任務品質下的計費成本 | [模型選擇與定價](11-models-and-pricing.md) |
| 支出上限 | 預算、群組、模型存取原則 | 支出對比預算；被阻擋的有用工作 | [企業治理](12-enterprise-governance.md) |

這是一份選擇指南，而非通用節省百分比的排名。

## 在原始範圍內解讀證據

| 證據類型 | 它能證明什麼 | 它無法證明什麼 |
|---|---|---|
| 手寫的前後對照組 | 措辭可以如何改變 | 實際的模型輸出、品質或典型的節省幅度 |
| 離線分詞器計數 | 該分詞器下的文字長度 | 供應商計費的用量或金錢上的節省 |
| 受控的回應風格比較 | 在其任務與控制條件下的輸出差異 | 整個工作階段的成本，或其他模型的行為 |
| 重複且經驗證的代理程式任務 | 在該執行框架下的任務成果與用量 | 對每個儲存庫或工作流程的保證 |
| 工具供應商的基準測試 | 一個值得測試的候選項目 | 對你帳單減少幅度的獨立證明 |

[Caveman 證據與三組對照通訊協定](05-output-control.md#caveman-optional-output-style)區分了預設回覆、一般簡潔與整體任務成本。[語言比較](03-language-comparison.md)包含語言對照表；[基準測試討論](13-outcome-per-token.md#benchmarks-useful-not-decisive)則涵蓋執行框架與分數的限制。

## 不要將節省百分比相加

兩種技巧可能移除的是相同的 token。它們的效果並不能相加。

舉例說明：如果輸出佔帳單的 10%，將該輸出減少 10%，在計入指示的額外負擔或行為變化之前，只會節省帳單的 1%。這是算術，並非實際量測到的 Caveman 結果。

請分別量測輸入、快取、輸出、（有提供時的）推理，以及總計費成本。請比較相同的任務與驗收檢查。關於計費單位，請使用[模型選擇與定價](11-models-and-pricing.md)。

## 記錄足以重現某項主張的內容

請註明來源、日期、模型、技能／工具版本、任務集、對照組、執行次數、分詞器或供應商用量，以及品質檢查。請標示供應商自行回報的結果與未經驗證的估計值。

來自單一任務或單次執行的結果，可以作為測試的建議。但它不應成為本指南中預設的節省範圍。
